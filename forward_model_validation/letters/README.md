# Letter reconstructions

This folder contains measurement-only spot-fold reconstructions for A–Z at the same 90% fullscreen, green-only presentation used for the letter calibration. Each reconstruction folds and averages 120 lenslet copies from its RAW16 measurement. The source letter is shown in each comparison image for evaluation only; it is not used by the reconstruction.

`measurements/` contains the 26 RAW16 camera frames. A, B, C, D, F, and O reuse earlier calibrated captures; the remaining letters were captured for this run at the model's 80 ms exposure and gain 0. `reconstructions/` contains each display-scale reconstruction, folded tile, and source comparison. `letter_reconstruction_montage.jpg` summarizes A–Z.
