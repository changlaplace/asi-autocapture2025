# Scene image assets

`source_photos/` contains the source photos, and `square_1600/` contains 20 RGB images processed to match the letter assets (1600 x 1600 pixels). `prepare_scene_assets.py` center-crops each photo to a square and resizes it with Lanczos; it does not add borders or stretch the scene. A contact sheet is included in `square_1600/contact_sheet.jpg`.

The camera experiment displayed every processed photo using the same path as the letter assets: 90% fullscreen scale, green channel only, 80 ms RAW16 exposure, gain 0. The display is not the entire 1600-square source: the app fits it to the 1920 x 1080 monitor, just as it does for the square letters.
